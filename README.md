# MotionCoach

Computer vision workout assistant for live webcam sessions and uploaded videos.
The product goal is observable repetition counting, joint-angle traces, and
contextual feedback for squat, push-up, biceps curl, and jumping jack.

This repository is in the planning stage. Application code has not started.
The implementation order, contracts, and engineering protocol live in:

- [Project scope](docs/project-scope.md)
- [Scope analysis](docs/scope-analysis.md)
- [Implementation plan](docs/implementation-plan.md)
- [Agent entry point](AGENTS.md)

Documentation is in Portuguese. The interface, API, and code will be in English.

MotionCoach is an educational self-observation tool. It does not diagnose
injury, prescribe training, or certify that a movement is safe.
