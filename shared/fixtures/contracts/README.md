# Fixtures de contrato

Exemplos sintéticos, sem imagem nem medição de movimento. Os sete arquivos
`valid/` são consumidos pelo Python e TypeScript. `invalid/cases.json` aplica
mutações sobre o exemplo do contrato identificado; `path` usa chaves/índices.
`nonfinite` injeta em memória o valor nomeado, preservando JSON válido em disco.

O resumo mantém os números ilustrativos do escopo, não resultados do produto.
A lista de eventos é abreviada; reconciliação de totais pertence ao motor e ao
relatório das ondas posteriores. Nenhuma fixture fecha avaliação científica.
